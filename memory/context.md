# Contexto: Atacado de Construção

**Data de Início**: 2026-04-30
**Status**: Em Desenvolvimento / Finalização de UI
**Stack Principal**: Next.js 15, TypeScript, Tailwind CSS, Supabase, Lucide React, SWR.

## Objetivo
Plataforma de e-commerce robusta para uma distribuidora de materiais de construção, focada em pronta entrega e experiência de compra premium para B2B e B2C.

## Escopo V1
- [x] Catálogo de Produtos dinâmico.
- [x] Dashboard Administrativo Glassmorphism.
- [x] CMS para banners e configurações.
- [x] Rodízio de vendedores via WhatsApp.
- [x] Calculadora de materiais integrada.
- [x] Layout 100% responsivo e premium.

## Decisões Técnicas
- **Supabase**: Backend-as-a-Service para autenticação, banco de dados e storage.
- **Tailwind v4**: Utilizado para estilização moderna e performance.
- **SWR**: Gerenciamento de estado do lado do cliente para dados dinâmicos.
- **Nexa Aesthetic**: Tipografia baseada em Montserrat (Book/Heavy) para visual premium.
